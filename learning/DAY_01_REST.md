# День 1 — REST-контракт

1. Заполни собственную таблицу всех endpoint'ов: ресурс, метод, входные данные, статусы, идемпотентность.
2. В Postman проверь: успешную регистрацию; дубликат username; неверный пароль; запрос к items без `Bearer`; создание и удаление item.
3. Для каждого ответа с ошибкой проверь `Content-Type: application/json` и все поля `ApiError`.
4. Письменно объясни, почему `POST` возвращает `201` и `Location`, а успешный `DELETE` — `204` без тела.
5. Отдельно объясни различие `400`, `401`, `404`, `409` на примерах этого API.
