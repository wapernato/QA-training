# Page Objects для SauceDemo

Создавай Page Object-классы в этом пакете по мере прохождения сценария:

- `LoginPage` — открытие сайта и авторизация;
- `InventoryPage` — список товаров, добавление товара, переход в корзину;
- `CartPage` — содержимое корзины и переход к оформлению;
- `CheckoutPage` — данные покупателя и завершение заказа.

Не помещай JUnit-проверки внутрь Page Object. Page Object должен взаимодействовать
со страницей и возвращать данные, а ожидаемый результат проверяй в тесте.
